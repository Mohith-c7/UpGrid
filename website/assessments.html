Assessments and coding tests

Tests that run where your students already are.

Set MCQ and coding tests for a drive. Students take them on their phone with a timer and question palette, and results are evaluated automatically.

Join the campus pilot

What the placement cell gets

MCQ tests

Build tests from a question bank. Marks are calculated automatically when the test ends.

Coding tests

Students write code in the app and run it against sample cases. Hidden test cases are used when they submit.

Server-side scoring and time

The server keeps the clock and computes scores. A phone cannot change either.

Results for staff

Per-student results and per-question outcomes for the cell to review and share with the recruiter.

Safe code execution

Student code runs in a separate sandboxed execution service, never on the application server.

Scheduled with the drive

Tests are scheduled like any other round, and students get a reminder.

What students see

Clear, fair and calm.

  • A visible countdown timer that cannot be reset on the phone.
  • A question palette showing answered, marked for review and unanswered questions.
  • Run results for coding questions with the time taken for each case.
  • No jumpy animations or surprises while the clock is running.

About integrity: we plan light-touch signals for staff to review. This is not a substitute for invigilation, and we do not plan camera or microphone recording.
